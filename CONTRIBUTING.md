# Contributing to Fastseo Website Reviewer

Thank you for your interest in improving Fastseo Website Reviewer.

## Before contributing

- Keep the existing website design and user experience intact unless a change is specifically requested.
- Avoid unnecessary changes to unrelated files.
- Keep the project suitable for static hosting.
- Test HTML, CSS, and JavaScript changes before submitting them.
- Do not commit API keys, passwords, tokens, or other private credentials.

## Pull requests

Please provide a clear description of:

1. What was changed.
2. Why the change was needed.
3. Which files were modified.
4. How the change was tested.

## Bug reports

When reporting a bug, include the browser, device, steps to reproduce the problem, and the expected versus actual behavior when possible.
